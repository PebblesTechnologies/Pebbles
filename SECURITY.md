# Security Policy

This repository holds the source for the Pebbles Technologies marketing
website (pebblestechnologies.com). It's a static site — no user accounts,
no server-side code, no database.

## Reporting a vulnerability

If you find a security issue with the website (for example, something
wrong with how the contact form handles data, a misconfigured header, or
exposed information that shouldn't be public), please report it privately
rather than opening a public issue.

**Contact:** info@pebblestechnologies.com

Please include:
- A description of the issue and its potential impact
- Steps to reproduce it
- Any relevant URLs or screenshots

We'll acknowledge reports within a few business days. Since this is a
small marketing site rather than an application handling sensitive user
data, please give us a reasonable amount of time to fix an issue before
disclosing it publicly.

## Scope

This policy covers pebblestechnologies.com and this repository only. It
does not cover third-party services the site links to or embeds (Google
Fonts, Plausible Analytics, FormSubmit).
